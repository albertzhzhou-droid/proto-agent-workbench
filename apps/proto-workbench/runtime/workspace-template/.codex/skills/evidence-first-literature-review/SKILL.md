# Evidence-First Literature Review

Start with the local source registry, then use the least broad approved external search needed. Corroborate publication identity across PubMed or Europe PMC and Crossref before relying on a citation.

Build a claim-evidence matrix containing the claim, source identifier, source type, support or contradiction, limitations, retrieval date, and confidence. Separate established findings, contested findings, hypotheses, and missing evidence. Retractions, corrections, inconsistent metadata, inaccessible full text, and negative searches remain visible.

Network-backed searches require the MCP network capability. Search results are evidence inputs, not proof that a biological component is safe, functional, orderable, or design-eligible. Feed supported claims and unresolved gaps into the Proto review packet.
